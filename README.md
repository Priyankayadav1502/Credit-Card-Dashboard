# 💳 Credit Card Analytics Dashboard

## 📊 Project Overview

The **Credit Card Analytics Dashboard** is an interactive data analytics project developed using **Microsoft Power BI** to analyze credit card transactions, revenue, customer activity, payment methods, card types, and key financial performance indicators.

The dashboard transforms transaction-level data into meaningful visual insights that can support business performance monitoring and decision-making.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze overall credit card transaction performance
* Monitor total revenue and transaction volume
* Understand customer activity and spending patterns
* Analyze revenue across different categories
* Compare payment methods such as Card and UPI
* Analyze revenue generated by different card types
* Monitor delinquency rate and credit utilization
* Identify top customers based on revenue
* Provide an interactive dashboard for business analysis

## 📈 Dashboard Features

### 1. Revenue Trend

A time-series visualization is used to monitor revenue fluctuations throughout the year and identify changes in transaction performance over time.

### 2. Revenue by Category

Revenue is analyzed across four major categories:

* Travel
* Fuel
* Shopping
* Food

The dashboard provides a visual comparison of the contribution of each category to total revenue.

### 3. Top 5 Customers

A table highlights the top five customers based on total revenue generated.

### 4. Revenue by City

The dashboard provides city-level revenue analysis with interactive filtering for:

* Delhi
* Lucknow
* Mumbai
* Pune

### 5. Payment Mode Analysis

Transactions are analyzed based on payment method:

* Card
* UPI

This helps compare customer preference across different payment modes.

### 6. Revenue by Card Type

Revenue is compared across:

* RuPay
* MasterCard
* Visa

This provides an overview of revenue contribution by card type.

### 7. Interactive Filters

The dashboard includes an interactive **City filter**, allowing users to analyze performance for individual cities.
